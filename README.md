# DSA8670 – Kanban Fundamentals with GitHub

Welcome to the **Kanban Fundamentals** assignment for DSA 8670: Business Analytics Applications & Projects.  
In this assignment, you will learn how to use GitHub’s **Projects** feature to manage work visually with a Kanban board.

---

## Purpose
Analytics projects don’t just require coding; they also require managing tasks, people, and deliverables.  
Kanban provides a simple yet powerful way to **visualize workflow, identify bottlenecks, and keep work moving**.  
This assignment introduces you to Kanban using **GitHub Projects and Issues**.

---

## Learning Goals
By completing this assignment, you will be able to:
- Explain the core ideas of Kanban.
- Create and configure a GitHub Project board.
- Represent tasks as Issues and organize them on a board.
- Apply labels, assignees, and due dates to manage work.
- Move Issues across workflow stages (*To Do → In Progress → Done*).
- Reflect on how Kanban supports analytics project delivery.

## Readings
To prepare for this assignment, complete the following readings:

1. **Essential Kanban Condensed** – David J. Anderson & Andy Carmichael  
   - *Introduction* and *Core Practices* (pp. 7–21).  

2. **Analytics: The Agile Way** – Phil Simon  
   - *Chapter 4: A Better Way to Work*  
   - *Chapter 5: Introducing Scrum (focus on the section on Kanban Boards)*  
   - *Note*: This reading is **Scrum-heavy**. You are not expected to master Scrum roles, ceremonies, or artifacts. Focus on the reasoning: smaller increments, visualizing work, and improving flow.
